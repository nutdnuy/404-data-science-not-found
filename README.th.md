# Data Science Skills

**ฟีเจอร์ที่แม่นที่สุดของโมเดล อาจเป็นฟีเจอร์ที่แอบเห็นอนาคต**

Agent Skills 12 ตัว สำหรับงาน Data Science ตั้งแต่รับโจทย์ธุรกิจ วิเคราะห์ข้อมูล
ทำความสะอาด สร้างฟีเจอร์ พัฒนาโมเดล ทำนาย ไปจนถึงรายงานที่ย้อนตรวจหลักฐานได้

[English](README.md) · [รายการสกิล](README.md#pick-a-skill) · [ตัวอย่างที่รันได้](examples/subscription-retention/README.md)

## ติดตั้ง

```bash
npx skills add nutdnuy/data-science-skills
```

เลือกสกิลและเครื่องมือที่ใช้ เช่น Codex, Claude Code หรือ Cursor ผ่านตัวติดตั้ง
ต้องมี Node.js ส่วน Python จำเป็นเฉพาะเมื่อจะรันเดโม

อยากเริ่มจากตัวเดียว:

```bash
npx skills add nutdnuy/data-science-skills --skill ds-leakage-audit
```

จากนั้นพิมพ์ใน Agent ว่า:

```text
ใช้ ds-leakage-audit ตรวจ notebook นี้ที
อยากรู้ว่าแต่ละฟีเจอร์มีอยู่จริง ณ เวลาที่เราจะทำนายหรือเปล่า
ตรวจการแบ่งข้อมูลและการใช้ test set ด้วย แล้วสรุปพร้อมหลักฐาน
```

ชื่อคำสั่งลัดและวิธีเรียกสกิลต่างกันตามเครื่องมือ ใช้ชื่อสกิลในคำขอได้
หากยังไม่ปรากฏ ให้รีเฟรชหรือเปิดเครื่องมือใหม่

## ครอบคลุมงานอะไรบ้าง

| งาน | สกิล |
| --- | --- |
| เก็บความต้องการและกำหนดผลสำเร็จ | `ds-requirements` |
| วิเคราะห์ทางเลือก รวมถึงวิธีใช้กฎ | `ds-solution-design` |
| สำรวจข้อมูล (EDA) | `ds-eda` |
| ทำความสะอาดข้อมูลพร้อมบันทึกผล | `ds-data-cleaning` |
| สร้างข้อค้นพบที่มีหลักฐานรองรับ | `ds-insight` |
| สร้างฟีเจอร์ที่ใช้ได้จริงตอนทำนาย | `ds-feature-engineering` |
| แบ่งข้อมูล เทียบ baseline เลือกและปรับโมเดล | `ds-model-development` |
| ประเมินโมเดลและอธิบายข้อจำกัด | `ds-model-evaluation` |
| ทำนายด้วยรูปแบบข้อมูลที่ตรวจสอบได้ | `ds-inference` |
| สร้างรายงานจากผลที่รันจริง | `ds-report` |
| ตรวจข้อมูลรั่วและการแอบใช้อนาคต | `ds-leakage-audit` |
| ประสานงานครบกระบวนการหรือต่องานเดิม | `ds-pipeline` |

แต่ละสกิลใช้แยกได้ และรักษารูปแบบไฟล์เดิมของโปรเจกต์ไว้ งานวิเคราะห์เชิงพรรณนา
ไม่จำเป็นต้องสร้างโมเดล สกิลเป็นคำแนะนำให้ Agent ทำงานรอบคอบขึ้น ผลจริงยังต้องตรวจสอบ

## ลองเดโม

ตัวอย่างใช้ข้อมูลสมาชิกแบบจำลองทั้งหมด มีคอลัมน์ที่สร้างหลังเกิดผลลัพธ์เพื่อสาธิต
ความเสี่ยงเรื่องข้อมูลรั่ว ใช้การแบ่งข้อมูลตามเวลา เทียบกับ baseline
และสร้างรายงานจากผลจริง โดยไม่ต้องใช้ API key หรือดาวน์โหลดชุดข้อมูล

ดูคำสั่งใน [คู่มือเดโม](examples/subscription-retention/README.md) หรือเปิด
[รายงานตัวอย่าง](examples/subscription-retention/sample-output/report.md) ได้ทันที
ผลจากข้อมูลจำลองไม่ใช่หลักฐานว่าโมเดลจะทำงานได้ดีเท่ากันกับข้อมูลจริง
